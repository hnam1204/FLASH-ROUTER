# Visual tokens

The host foundation uses a restrained paper, graphite, and electric-lime palette. Feature pages consume the shared token layer but define their own layout and selectors in paired `.razor.css` files.

- Accent is reserved for status, focus, and primary action emphasis.
- Surfaces use a single small radius rule and thin borders.
- Body copy stays readable at normal zoom and supports 200% zoom without horizontal overflow.
- The shell uses Segoe UI Variable when available and Cascadia Code for operational labels.
